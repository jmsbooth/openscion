## Remaining blockers

1. **Native Windows execution**: actual NTFS ACL inheritance, symlinks/junctions/reparse points, reserved names, no-overwrite publication and casefold interactions were not tested. Windows cross-compilation alone is insufficient.
2. **Power-loss/process-kill testing**: staged-write, fsync and transaction failure points need deterministic kill/restart evidence on target filesystems. Unit tests of abandoned staging files are not equivalent.
3. **Independent security review**: separate approver must inspect TOCTOU/same-UID races and supply-chain/license/cryptographic evidence and record disposition.
4. **No CI**: GitHub Actions credits not used; future acceptance requires archived native manual results.
5. **Merges**: PRs #2/#3/#4 remain draft pending these gates. No protection was bypassed, no merge to main.
